# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a vulnerability

Please do not post vulnerability details in a public issue. Private vulnerability reporting is not currently enabled on this repository, so contact the owner through their GitHub profile and share details only once a private channel exists.

This is a personal practice project, so responses are best effort.

## Scope

This repository contains a browser client only. Authentication, authorization and rate limiting belong to the API that serves it, which is not part of this repository.

The most recent review is in [docs/SECURITY_AUDIT.md](docs/SECURITY_AUDIT.md).
